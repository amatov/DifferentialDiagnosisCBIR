## Quick start

This repository implements a Content-Based Image Retrieval (CBIR) /
reverse image search system in Python. See
[DEPENDENCIES.md](DEPENDENCIES.md) for the required third-party packages
(OpenCV with the `xfeatures2d` module, ElasticSearch, scikit-learn,
scipy, imgaug) and the image-dataset folders the scripts expect but
which are not included in this repository.

## Repository contents

- `ReverseImageSearchSIFT.py`, `getHistogram.py` -- build a SIFT-based
  bag-of-words model over an image collection.
- `query_sift_es.py`, `query_sift_1000_es.py`, `query_surf_es.py` --
  query the model via ElasticSearch using SIFT or SURF descriptors.
- `demo_query_1.py` -- a standalone demo query against a saved model.
- `sift_test*.py`, `surf_test.py`, `canny_edge_test.py` -- smaller
  standalone tests/experiments with individual feature-descriptor and
  edge-detection methods.
- `test_sift_es*.py`, `test_surf_es.py`, `test_suft_es25k_par.py`,
  `test_minhash.py`, `test_distorted_images.py` -- larger-scale test
  scripts, including a MinHash/locality-sensitive-hashing variant and a
  robustness test against distorted images.
- `stats.py`, `stats_mp.py` -- descriptor statistics, with a
  multiprocessing variant.
- `des.sift.pickle`, `des.surf.pickle`, `des.test.pickle` -- precomputed
  descriptor data, in `data/`.
- `sift_keypoints.jpg`, `surf_keypoints.jpg` -- example keypoint
  visualizations, in `media/`.
- Hardcoded absolute paths to the original author's machine are flagged
  with a `# EDIT:` comment directly above them.

## About

Python code I wrote to implement a Reverse Image Search / Content-Based Image Retrieval (CBIR)

 Based on the feature descriptors generated by the scale-invariant feature transform and the bag-of-words model (BoW), it performs reverse image search; content-based image retrieval query is accomplished via ElasticSearch using ranking based on a k-means clustering algorithm; see my preliminary demo of the BoW ranking: https://vimeo.com/365998906/e94e02a8af

For further information, see: https://www.researchgate.net/publication/382593670_Quantitative_Video_Microscopy_in_Medicine
